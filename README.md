# CYBR 3570 Cryptographic Toolkit

This repository is the starting point for the semester-long cryptographic toolkit.

## Week 1 - v0.1

You will implement educational versions of:

- Caesar encryption
- Caesar decryption
- Brute force Caesar attack

These modules are for learning only and must not be used to protect real data.

## Setup

```bash
python -m venv .venv
source .venv/bin/activate  # macOS/Linux
.venv\Scripts\activate   # Windows PowerShell
pip install -r requirements.txt
pytest
```
